# FORGE — Coach Maxime

App perso de coaching muscu : programme généré, macros calculées, chat avec Coach Maxime (IA).

## Clé API Coach Maxime

Le chat avec Coach Maxime appelle l'API Anthropic directement depuis ton navigateur.
Au premier message, l'app te demande ta clé API (créée sur https://console.anthropic.com).
Elle est stockée uniquement dans le localStorage de ton navigateur.

⚠️ Ne partage jamais publiquement le lien de ton site une fois ta clé enregistrée dessus — reste sur un usage perso.
